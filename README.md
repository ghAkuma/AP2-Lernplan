# AP2-Lernplan – Kaufmann/Kauffrau im E-Commerce (IHK Berlin, Winter 2026/27)

Ein Lernpaket für die schriftliche Abschlussprüfung Teil 2 am **Mi 25.11.2026**, gedacht zum Lernen mit **Claude**. Es enthält:
- einen Tagesplan bis zur Prüfung
- Lernzettel zu allen 91 Unterrichtsdokumenten (e-compedia.de / OSZ Handel 1)
- eine Formelsammlung
- WiSo, das nicht im Schulmaterial steht
- ein Glossar Deutsch–Englisch
- Prüfungsinfos und einen Leitfaden fürs Fachgespräch

## Was du brauchst
- ein kostenloses **GitHub-Konto** und die Einladung zu diesem Repo
- **Claude Code**, als Desktop-App oder im Terminal, mit einem Claude-Abo, das Claude Code enthält
- unter Windows zusätzlich **Git für Windows**, das braucht Claude Code ohnehin
- einen **nicht programmierbaren Taschenrechner**, denn das ist das einzige erlaubte Hilfsmittel in der Prüfung

## Einmal einrichten (ca. 10 Min.)
1. **Eigene Kopie anlegen:** Oben auf dieser Seite **„Use this template“ → „Create a new repository“** klicken, einen Namen wählen (z. B. `AP2`) und **Private** einstellen. Bitte nicht in diesem Repo selbst arbeiten, denn hier lernen mehrere Leute.
2. **Auf den PC holen:** Claude Code in einem leeren Ordner öffnen und sagen: „Klone `https://github.com/<dein-github-name>/AP2` in diesen Ordner.“
3. **Erste Session:** Claude Code im neuen Ordner öffnen und sagen: „Session 06.10. laut LERNPLAN.md“. Das ist der Kick-off mit Diagnose-Test (90 Min.). **Auch wenn du später einsteigst, fängst du damit an.** Claude passt danach den Plan an deinen Starttermin an.

Halte für den Kick-off bereit:
- dein Ergebnis aus Teil 1
- den Stand deines Reports
- das Gebiet, das dein Ausbilder für das Fachgespräch gemeldet hat

## So läuft jede Session
1. „Hol den aktuellen Stand von GitHub.“
2. „Session <Datum> laut LERNPLAN.md“
3. Claude fragt fällige Lernkarten ab, erklärt den neuen Stoff, stellt dir Prüfungsaufgaben und korrigiert streng nach IHK-Maßstab.
4. Am Ende trägt Claude deinen Stand in `FORTSCHRITT.md` ein und lädt ihn nach deinem OK auf GitHub hoch. So hast du deinen Stand auch an einem anderen PC.

## Wichtig
- **Zeichen in den Lernzetteln:**
  - ⚠️ = Die Musterlösung im Original ist falsch, im Zettel steht die richtige Lösung.
  - 🔎 = Ergänzung, die nicht im Original steht. Meist hat sich das Recht seit 2020–2023 geändert.
  - ° im Lernplan = Zettel nur überfliegen.
- **Ohne Gewähr:** Die Lernzettel hat Claude aus den Unterrichtsdokumenten erstellt und mehrfach gegengeprüft, Fehler sind trotzdem möglich. Recht und Zahlen haben den Stand 06.10.2026. Bei Widersprüchen gilt im Zweifel, was im Unterricht gesagt wurde.
- **Übungsfälle:** Die Fälle spielen in erfundenen Online-Shops für Angelzubehör. Claude überträgt sie in den Sessions gern auf deinen eigenen Ausbildungsbetrieb.
- **Privat halten:** Das Schulmaterial ist nur für den nicht-kommerziellen Gebrauch durch Schüler und Lehrer gedacht. Deine Kopie also auf **Private** lassen und nicht außerhalb der Klasse weitergeben.
- **Nie speichern:** PIN, Passwörter oder Zugangsdaten. Alles im Ordner landet auf GitHub.
