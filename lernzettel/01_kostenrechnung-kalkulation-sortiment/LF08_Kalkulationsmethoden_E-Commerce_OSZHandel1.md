# Kalkulationsmethoden: Vorwärts-, Rückwärts- und Differenzkalkulation (LF08, LF08_Kalkulationsmethoden_E-Commerce_OSZHandel1)
**Prüfungszuordnung:** Teil 2-1 Geschäftsprozesse im E-Commerce > 02 Waren- oder Dienstleistungssortiment mitgestalten und online bewirtschaften > 04 bei Preiskalkulation mitwirken > 02 Kalkulationsmethoden (Seitenkopf der PDF: Lernfeld 8 – Wertschöpfungsprozesse erfolgsorientiert steuern)
**Schwierigkeit:** 3 | **Rechenanteil:** ja | **Lernzeit:** ca. 100 Min

## Kerninhalt

### 1. Definition Kalkulationsschema
Mit einem Kalkulationsschema können Unternehmen im Zuge der **Zuschlagskalkulation** anhand eines **standardisierten Schemas** die verschiedenen Kosten ihrer Produkte auflisten und berechnen. Dadurch wird deutlich, wie sich die einzelnen **Kostenbestandteile im Vergleich zu den Gesamtkosten** verhalten.

### 2. Die drei Kalkulationsarten (Tabelle im Material)

| | Vorwärtskalkulation | Rückwärtskalkulation | Differenzkalkulation |
|---|---|---|---|
| Richtung | vom **Listeneinkaufspreis** zum **Verkaufspreis** | vom **vorgegebenen Verkaufspreis** zum **maximalen Einkaufspreis** | **vorwärts** bis zu den **Selbstkosten** und **rückwärts** bis zum **Barverkaufspreis**, um dann den **Gewinn** festzustellen |
| Typische Frage | „Zu welchem Preis müssen wir verkaufen?" | „Wie viel dürfen wir beim Lieferanten höchstens zahlen?" (Marktpreis ist vorgegeben) | „Wie viel Gewinn bleibt bei EK und VK, die beide feststehen?" |
| Vereinfachung | **Kalkulationszuschlag** und **Kalkulationsfaktor** | **Handelsspanne** | – |

**Das Schema ist bei allen Arten gleich.**

### 3. Handelskalkulationsschema mit Rechenrichtung (Bild in der PDF, vollständig)

| Position | Vorwärts ↓ | Rückwärts ↑ | Differenz |
|---|---|---|---|
| **Listeneinkaufspreis (LEP)** | Ausgangswert | Ergebnis | Ausgangswert ↓ |
| − Liefererrabatt | vom Hundert | **im Hundert** | vom Hundert |
| = **Zieleinkaufspreis (ZielEP)** | | | |
| − Liefererskonto | vom Hundert | **im Hundert** | vom Hundert |
| = **Bareinkaufspreis (BarEP)** | | | |
| + Bezugskosten | in € | in € (abziehen) | in € |
| = **Bezugspreis / Einstandspreis (EP)** | | | |
| + Handlungskostenzuschlag (HKZ) | vom Hundert | **über Hundert** | vom Hundert |
| = **Selbstkosten (SKP)** | | | (vorwärts bis hierher) |
| + Gewinnzuschlag | vom Hundert | **über Hundert** | **Subtraktion**: BarVP − SKP |
| = **Barverkaufspreis (BarVP)** | | | (rückwärts bis hierher) |
| + Kundenskonto | **im Hundert** | vom Hundert | vom Hundert ↑ |
| + Vertreterprovision | **im Hundert** | vom Hundert | vom Hundert ↑ |
| = **Zielverkaufspreis (ZielVP)** | | | |
| + Kundenrabatt | **im Hundert** | vom Hundert | vom Hundert ↑ |
| = **Nettoverkaufspreis (NettoVP, Listenverkaufspreis netto)** | | | |
| + Umsatzsteuer | vom Hundert | **über Hundert** | **über Hundert** ↑ |
| = **Bruttoverkaufspreis (BruttoVP)** | Ergebnis | Ausgangswert | Ausgangswert ↑ |

**Bedeutung der Rechenarten:**
- **vom Hundert:** Der Ausgangswert ist 100 %. Prozentwert = Grundwert × p ÷ 100. (z. B. 10 % Rabatt von 830 € = 83 €)
- **im Hundert:** Der **gesuchte** Wert ist 100 %, der bekannte Wert ist **weniger** als 100 % (100 % − p). Rechnen: bekannter Wert ÷ (100 − p) × 100. (z. B. BarVP = 98 % → ZielVP = BarVP ÷ 0,98)
- **über (auf) Hundert:** Der **gesuchte** Wert ist 100 %, der bekannte Wert ist **mehr** als 100 % (100 % + p). Rechnen: bekannter Wert ÷ (100 + p) × 100. (z. B. Brutto = 119 % → Netto = Brutto ÷ 1,19)

**Rechenzeichen im Arbeitsschema (Bild Seite 2 und 4):**
- Vorwärts (von oben nach unten): LEP − LieRab % = ZielEP − LieSko % = BarEP + Bezugsk € = EP + HKZ % = SKP + GewZ % = BarVP + KuSko % = ZielVP + KuRab % = NettoVP + USt % = BruttoVP €
- Rückwärts (von unten nach oben): BruttoVP − USt % = NettoVP − KuRab % = ZielVP − KuSko % = BarVP − GewZ % = SKP − HKZ % = EP − Bezugsk € = BarEP + LieSko % = ZielEP + LieRab % = LEP

## Formeln & Rechenwege

| Schritt | Formel (vorwärts) | Formel (rückwärts) |
|---|---|---|
| Liefererrabatt | ZielEP = LEP × (1 − r) | LEP = ZielEP ÷ (1 − r) |
| Liefererskonto | BarEP = ZielEP × (1 − s) | ZielEP = BarEP ÷ (1 − s) |
| Bezugskosten | EP = BarEP + Bezugskosten | BarEP = EP − Bezugskosten |
| Handlungskosten | SKP = EP × (1 + hkz) | EP = SKP ÷ (1 + hkz) |
| Gewinn | BarVP = SKP × (1 + g) | SKP = BarVP ÷ (1 + g) |
| Kundenskonto | ZielVP = BarVP ÷ (1 − ks) | BarVP = ZielVP × (1 − ks) |
| Kundenrabatt | NettoVP = ZielVP ÷ (1 − kr) | ZielVP = NettoVP × (1 − kr) |
| Umsatzsteuer | BruttoVP = NettoVP × 1,19 | NettoVP = BruttoVP ÷ 1,19 |
| Differenzkalkulation | Gewinn € = BarVP − SKP; Gewinn % = Gewinn € × 100 ÷ SKP | |

(r, s, hkz, g, ks, kr = Prozentsätze als Dezimalzahl, z. B. 10 % = 0,10)

**Mini-Beispiel vorwärts (Angelshop, Wobbler-Set):**

| Position | % | € |
|---|---|---|
| Listeneinkaufspreis | | 50,00 |
| − Liefererrabatt | 20 % | 10,00 |
| = Zieleinkaufspreis | | 40,00 |
| − Liefererskonto | 2 % | 0,80 |
| = Bareinkaufspreis | | 39,20 |
| + Bezugskosten | | 0,80 |
| = Bezugspreis | | 40,00 |
| + Handlungskosten | 25 % | 10,00 |
| = Selbstkosten | | 50,00 |
| + Gewinn | 10 % | 5,00 |
| = Barverkaufspreis (= Ziel- = Nettoverkaufspreis, da im Onlineshop kein Kundenskonto/-rabatt) | | 55,00 |
| + USt | 19 % | 10,45 |
| = Bruttoverkaufspreis | | **65,45** |

**Mini-Beispiel „im Hundert":** BarVP 98,00 €, Kundenskonto 2 % → ZielVP = 98,00 ÷ 0,98 = **100,00 €** (Skonto 2,00 €). Falsch wäre 98,00 × 1,02 = 99,96 €: Dann bekäme der Kunde 2 % von 99,96 = 2,00 € Skonto und zahlte nur 97,96 €.

**Mini-Beispiel Differenzkalkulation:** BarVP 55,00 €, Selbstkosten 50,00 € → Gewinn 5,00 € = 5,00 × 100 ÷ 50,00 = **10 %**.

## Aufgaben aus dem Material

### Aufgabe 1 – Vorwärtskalkulation (Laptop)
Ein Computerladen bezieht Laptops zu **830,00 €** je Stück. Lieferrabatt **10 %**, bei Zahlung innerhalb von 10 Tagen **3 % Skonto**. Berechnen Sie den Bruttoverkaufspreis bei: **20 % Handlungskostenzuschlag, 18 % Gewinn, 7 % Kundenrabatt, 2 % Kundenskonto** (USt 19 %).

**Original-Lösung (Tabelle im Bild):**

| Position | % | € |
|---|---|---|
| LEP | | 830,00 |
| − LieRab | 10 % | 83,00 |
| = ZielEP | | 747,00 |
| − LieSko | 3 % | 22,41 |
| = BarEP | | 724,59 |
| + Bezugsk | | – |
| = EP | | 724,59 |
| + HKZ | 20 % | 144,92 |
| = SKP | | 869,51 |
| + GewZ | 18 % | 156,51 |
| = BarVP | | 1.026,02 |
| + KuSko | 2 % | 20,52 |
| = ZielVP | | 1.046,54 |
| + KuRab | 7 % | 73,26 |
| = NettoVP | | 1.119,80 |
| + USt | 19 % | 212,76 |
| = BruttoVP | | **1.332,56** |

⚠️ Hinweis: **Fehler in der Musterlösung.** Kundenskonto und Kundenrabatt wurden **vom Hundert** gerechnet (1.026,02 × 2 %, 1.046,54 × 7 %). Laut dem eigenen Schema im Material sind sie in der Vorwärtskalkulation **im Hundert** zu rechnen, weil der Kunde Skonto vom Zielverkaufspreis und Rabatt vom Listenverkaufspreis abzieht. Bis zum Barverkaufspreis (1.026,02 €) ist die Lösung richtig. Korrekt ab dort:

| Position | % | Rechnung | € |
|---|---|---|---|
| = BarVP (98 %) | | | 1.026,02 |
| + KuSko | 2 % i. H. | 1.026,02 ÷ 0,98 − 1.026,02 | 20,94 |
| = ZielVP (100 % bzw. 93 %) | | 1.026,02 ÷ 0,98 | 1.046,96 |
| + KuRab | 7 % i. H. | 1.046,96 ÷ 0,93 − 1.046,96 | 78,80 |
| = NettoVP | | 1.046,96 ÷ 0,93 | 1.125,76 |
| + USt | 19 % v. H. | 1.125,762 × 0,19 | 213,89 |
| = **BruttoVP** | | 1.125,762 × 1,19 = 1.339,657 | **1.339,66 €** |

Probe: 1.125,76 − 7 % (78,80) = 1.046,96; 1.046,96 − 2 % (20,94) = 1.026,02 ✓.

Rundungshinweis: Prüfungssicher ist **1.339,66 €**, weil nach der AkA-Regel die Zwischenwerte ungerundet im Taschenrechner bleiben (NettoVP 1.125,762 €). Wer mit dem auf Cent gerundeten NettoVP 1.125,76 € weiterrechnet (1.125,76 + 213,89), kommt auf 1.339,65 €.

### Aufgabe 2 – Rückwärtskalkulation (Tablet)
Der Computerladen möchte Tablets zum **Bruttoverkaufspreis von 980,00 €** aufnehmen. Wie hoch darf der **Listenpreis** des Lieferanten sein bei **15 % Rabatt, 5 % Skonto, 30 % Handlungskosten, 15 % Gewinn, 19 % USt**? (Kein Kundenrabatt/-skonto, keine Bezugskosten.)

**Original-Lösung (Tabelle im Bild, von unten nach oben gerechnet):**

| Position | % | € |
|---|---|---|
| BruttoVP | | 980,00 |
| − USt | 19 % | 156,47 |
| = NettoVP = ZielVP = BarVP | | 823,53 |
| − GewZ | 15 % | 107,42 |
| = SKP | | 716,11 |
| − HKZ | 30 % | 165,26 |
| = EP = BarEP | | 550,86 |
| + LieSko | 5 % | 28,99 |
| = ZielEP | | 579,85 |
| + LieRab | 15 % | 102,33 |
| = **LEP** | | **682,16** |

⚠️ Hinweis: Rechenweg (über/im Hundert) richtig, aber das Lösungsblatt mischt zwei Rundungswege. Die Zwischenwerte 550,86 / 579,85 / 28,99 / 102,33 € sind die ungerundet gerechneten Werte, das Endergebnis 682,16 € entsteht dagegen nur, wenn man jeden Zwischenwert auf Cent rundet. Deshalb passt 579,85 + 102,33 = 682,18 nicht zum Ergebnis. Prüfungssicher nach der AkA-Regel (Zwischenergebnisse ungerundet im Taschenrechner, nur das Endergebnis kaufmännisch runden):

| Schritt | Taschenrechner | notiert | Rechenart |
|---|---|---|---|
| 980,00 ÷ 1,19 | 823,5294 | 823,53 (USt 156,47) | über Hundert |
| ÷ 1,15 | 716,1125 | 716,11 (Gewinn 107,42) | über Hundert |
| ÷ 1,30 | 550,8558 | 550,86 (HK 165,26) | über Hundert |
| ÷ 0,95 | 579,8482 | 579,85 (Skonto 28,99) | im Hundert |
| ÷ 0,85 | 682,1744 | **682,17 €** (Rabatt 102,33) | im Hundert |

Der Listeneinkaufspreis darf höchstens **682,17 €** betragen. Wer jeden Zwischenwert auf Cent rundet, rechnet 716,11 ÷ 1,30 = 550,85 → ÷ 0,95 = 579,84 → ÷ 0,85 = 682,16 € (so das Lösungsblatt). Im Schema notierst du die Zeilen mit Cent-Beträgen, im Taschenrechner rechnest du ungerundet weiter.

### Aufgabe 3 – Differenzkalkulation (PC)
Barverkaufspreis **1.523,00 €**, Selbstkosten **1.109,00 €**. Wie hoch ist der Gewinn oder Verlust in Prozent?
**Lösung (korrekt):** 1.523 − 1.109 = 414 € Gewinn; 414 × 100 ÷ 1.109 = **37,33 % Gewinn** (bezogen auf die Selbstkosten).

## Ergänzungen & Aktualisierungen
🔎 Ergänzung (nicht im Original): Die im Material genannten **Vereinfachungen** werden dort nicht berechnet. Standardformeln der Handelskalkulation (Bezugspreis = Einstandspreis; Verkaufspreis = Listenverkaufspreis **netto**):

| Kennzahl | Formel | Anwendung |
|---|---|---|
| **Kalkulationszuschlag** (%) | (NettoVP − Bezugspreis) ÷ Bezugspreis × 100 | Vorwärts: NettoVP = Bezugspreis × (1 + KZ/100) |
| **Kalkulationsfaktor** | NettoVP ÷ Bezugspreis | Vorwärts: NettoVP = Bezugspreis × KF |
| **Handelsspanne** (%) | (NettoVP − Bezugspreis) ÷ NettoVP × 100 | Rückwärts: Bezugspreis = NettoVP × (1 − HS/100) |
| Umrechnung | HS = KZ × 100 ÷ (100 + KZ); KZ = HS × 100 ÷ (100 − HS) | |

Beispiel Wobbler-Set oben: Bezugspreis 40,00 €, NettoVP 55,00 € → KZ = 15 ÷ 40 × 100 = **37,5 %**; KF = 55 ÷ 40 = **1,375**; HS = 15 ÷ 55 × 100 = **27,27 %**.
Beispiel Laptop (korrigiert): Bezugspreis 724,59 €, NettoVP 1.125,76 € → KZ ≈ 55,37 %, KF ≈ 1,5537, HS ≈ 35,64 %.
Hinweis: Manche Lehrbücher (v. a. Einzelhandel) beziehen den Kalkulationsfaktor auf den **Bruttoverkaufspreis**. Immer auf die Angabe in der Aufgabe achten.

🔎 Ergänzung (nicht im Original): **Preisangaben gegenüber Verbrauchern** (Onlineshop) müssen nach der Preisangabenverordnung **Gesamtpreise inkl. USt** sein (§ 3 PAngV); bei Preisermäßigungen ist zusätzlich der **niedrigste Gesamtpreis der letzten 30 Tage** anzugeben (§ 11 PAngV, seit 28.5.2022). Für die Kalkulation heißt das: Der Bruttoverkaufspreis ist der Preis, den der Kunde im Shop sieht.

## Prüfungsfallen
- **vom / im / über Hundert** ist die häufigste Fehlerquelle:
  - Vorwärts: Rabatt, Skonto (Einkauf), HKZ, Gewinn, USt = **vom Hundert**; Kundenskonto, Vertreterprovision, Kundenrabatt = **im Hundert**.
  - Rückwärts: USt, Gewinn, HKZ = **über Hundert**; Kundenrabatt, Kundenskonto = **vom Hundert**; Liefererskonto, Liefererrabatt = **im Hundert**.
- **Bezugskosten** (Fracht, Verpackung, Zoll) sind ein **Euro-Betrag**, kein Prozentsatz. Rückwärts werden sie **abgezogen**.
- **Reihenfolge Einkauf:** erst Rabatt (vom LEP), dann Skonto (vom ZielEP). Skonto nie vom Listenpreis rechnen.
- **Reihenfolge Verkauf (vorwärts):** BarVP → + Kundenskonto → ZielVP → + Kundenrabatt → NettoVP. Rabatt und Skonto nicht vertauschen.
- 🔎 Ergänzung (nicht im Original): **Kundenskonto und Vertreterprovision gemeinsam:** Beide werden vom Zielverkaufspreis berechnet. Die Prozentsätze daher addieren und zusammen im Hundert rechnen (z. B. 2 % Skonto + 5 % Provision → BarVP = 93 % des ZielVP, ZielVP = BarVP ÷ 0,93), nicht nacheinander.
- **Differenzkalkulation:** Gewinn in % bezieht sich auf die **Selbstkosten**, nicht auf den Verkaufspreis.
- **Bezugspreis = Einstandspreis** (zwei Namen für denselben Wert).
- **Kalkulationszuschlag** (Basis Bezugspreis) vs. **Handelsspanne** (Basis Verkaufspreis): Die Handelsspanne ist bei gleichem Euro-Betrag immer **kleiner** als der Kalkulationszuschlag.
- **Rundung:** Im Schema stehen Cent-Beträge, gerechnet wird aber mit dem ungerundeten Wert im Taschenrechner weiter; nur das Endergebnis wird kaufmännisch gerundet (AkA-Hinweise, sofern die Aufgabe nichts anderes vorgibt). Nicht zwei Rundungswege mischen (das Lösungsblatt zu Aufgabe 2 notiert ungerundete Zwischenwerte, das Endergebnis aber mit gerundeten). Abweichungen von 1 Cent durch Rundung im Lösungsweg offenlegen. Ungerundet durchgerechnet: Laptop 1.339,66 € (statt 1.339,65 €), Tablet 682,17 € (statt 682,16 €).

## Lernkarten
**F:** Nennen Sie die drei Kalkulationsarten und ihre Rechenrichtung.
**A:** Vorwärtskalkulation (vom Listeneinkaufspreis zum Verkaufspreis), Rückwärtskalkulation (vom vorgegebenen Verkaufspreis zum maximalen Einkaufspreis), Differenzkalkulation (vorwärts bis zu den Selbstkosten, rückwärts bis zum Barverkaufspreis, Gewinn als Differenz).

**F:** Wann setzt ein Onlinehändler die Rückwärtskalkulation ein?
**A:** Wenn der Verkaufspreis vom Markt vorgegeben ist (z. B. durch Preisvergleichsportale) und ermittelt werden muss, welchen Einkaufspreis man beim Lieferanten höchstens zahlen darf.

**F:** Nennen Sie das Handelskalkulationsschema vom Listeneinkaufspreis bis zum Bezugspreis.
**A:** Listeneinkaufspreis − Liefererrabatt = Zieleinkaufspreis − Liefererskonto = Bareinkaufspreis + Bezugskosten = Bezugspreis (Einstandspreis).

**F:** Was bedeutet „im Hundert" und wo wird es in der Vorwärtskalkulation angewendet?
**A:** Der gesuchte Wert ist 100 %, der bekannte Wert ist (100 − p) %. Vorwärts bei Kundenskonto, Vertreterprovision und Kundenrabatt.

**F:** Bruttoverkaufspreis 980,00 € (19 % USt). Wie hoch ist der Nettoverkaufspreis und welche Rechenart wird verwendet?
**A:** 980,00 ÷ 1,19 = 823,53 € (über Hundert).

**F:** Ein Lieferant bietet einen Köderkoffer für 120,00 € Listenpreis mit 25 % Rabatt und 2 % Skonto an, Bezugskosten 2,40 €. Berechnen Sie den Bezugspreis.
**A:** 120,00 − 30,00 = 90,00 (ZielEP); 90,00 − 1,80 = 88,20 (BarEP); 88,20 + 2,40 = 90,60 € Bezugspreis.

**F:** Selbstkosten 80,00 €, Gewinnzuschlag 15 %. Wie hoch ist der Barverkaufspreis?
**A:** 80,00 × 1,15 = 92,00 € (Gewinn 12,00 €, vom Hundert).

**F:** Barverkaufspreis 92,00 €, Selbstkosten 80,00 €. Wie hoch ist der Gewinn in Prozent?
**A:** 12,00 × 100 ÷ 80,00 = 15 % (Differenzkalkulation, Basis Selbstkosten).

**F:** Barverkaufspreis 1.026,02 €, Kundenskonto 2 %. Wie hoch ist der Zielverkaufspreis?
**A:** 1.026,02 ÷ 0,98 = 1.046,96 € (im Hundert).

**F:** Bezugspreis 40,00 €, Nettoverkaufspreis 55,00 €. Berechnen Sie Kalkulationszuschlag, Kalkulationsfaktor und Handelsspanne.
**A:** KZ = 15 ÷ 40 × 100 = 37,5 %; KF = 55 ÷ 40 = 1,375; HS = 15 ÷ 55 × 100 = 27,27 %.

**F:** Ein Marktpreis für eine Rolle liegt bei 59,50 € brutto. Die Handelsspanne beträgt 40 %. Welchen Bezugspreis darf die Rolle höchstens haben?
**A:** Netto 59,50 ÷ 1,19 = 50,00 €; Bezugspreis = 50,00 × (1 − 0,40) = 30,00 €.

**F:** Warum wird in der Rückwärtskalkulation der Gewinn „über Hundert" herausgerechnet?
**A:** Weil der Gewinnzuschlag auf die Selbstkosten (= 100 %) berechnet wurde; der bekannte Barverkaufspreis entspricht also 100 % + Gewinn-%.

**F:** Was ist der Unterschied zwischen Kalkulationszuschlag und Handelsspanne?
**A:** Der Kalkulationszuschlag bezieht den Rohgewinn (NettoVP − Bezugspreis) auf den Bezugspreis, die Handelsspanne auf den Nettoverkaufspreis.
